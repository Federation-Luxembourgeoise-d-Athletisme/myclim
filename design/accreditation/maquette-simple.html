Une seule matrice « rôle × zone » pour tous les badges : rôles bénévoles, équipes organisation, Judge, Press, Photographer, Athlete, Coach. Chaque ligne a sa couleur de bande et son sous-rôle imprimé (voir maquette-organisation.html).

Aujourd'hui (9 onglets)

  1. Personnes : choisir le type (Bénévoles / Juges / Presse)
  2. « + File » sur chaque ligne
  3. Onglet Impression : « Générer les 2 PDF » (un par type)
  4. Onglet Retrait & suivi : ranger, remettre
  5. Onglet Historique pour savoir ce qui a été imprimé
  6. Athlètes / coachs : en bas de l'onglet Impression

Proposé (4 onglets)

  1. Badges : tout le monde dans une liste, filtrée par étape et par catégorie
  2. Cocher → « Imprimer » : le PDF sort, les badges passent « Imprimé »
  3. Guichet : chercher le nom → « Remis »
  4. L'historique est dans la fiche de chaque personne
  5. Badges sans nom : dans le même écran
  6. « À traiter » regroupe ce qui demande une action (réimprimer, récupérer)
